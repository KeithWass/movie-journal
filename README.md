# Movie Journal

A full stack web application that allows users to discover, save and organise movies into a personal journal as well as have movies recommended depending on personal tastes.

## Tech Stack

- Hapi.js
- Node.js
- Prisma
- PostgreSQL
- React
- Jest

## Current Status

Week 1 
Endpoints:

- POST /movies
- GET /movies
- GET /movies/{id}
- PATCH /movies/{id}
- DELETE /movies/{id}
